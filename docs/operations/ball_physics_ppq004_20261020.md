## 是否需要按球速适配

统一参数不表示忽略速度：现有加速度为
`g - drag_k*|v|*v + magnus_k*(omega × v)`，阻力本身随速度平方变化。这里检验的是系数是否还需要额外依赖速度。

分速检验只用每段前 150 ms 估计速度与旋转，不读取测试弧的未来速度来选模型。分界由训练集速度三分位数确定，约 3.520 和 4.645 m/s。统一/分速模型均使用完全相同的 200 段训练弧，避免“训练样本不同”冒充速度收益。该检验是按初始工作速度分组的常系数模型，尚不是随瞬时速度连续变化的物理定律。

| 速度段 | 训练 / 测试数 | 拟合阻力 / Magnus | 统一终点中位 / P90，mm | 分速终点中位 / P90，mm |
| --- | ---: | --- | ---: | ---: |
| <3.520 m/s | 67 / 5 | 0.129187 / 0.002708 | 14.624 / 42.975 | 12.917 / 38.671 |
| 3.520–4.645 m/s | 66 / 10 | 0.129147 / 0.003431 | 20.885 / 58.725 | 19.526 / 49.956 |
| >4.645 m/s | 67 / 9 | 0.123899 / 0.004766 | 22.152 / 77.192 | 16.373 / 69.455 |

该次相同 24 段测试整体由 20.885/61.080 降至 16.708/51.710 mm。但仅有 5 个测试时间块，10 秒配对块重采样下，中位差值为 -4.177 mm，95% 百分位范围 **-5.108 至 +2.408 mm**，仍跨零；低速留出只有 5 段。速度与旋转、弧长、录制时间相关，这些分组系数差异不能单独证明空气动力系数随速度改变。

再作时间顺序复核：只用第一文件 78 段训练，第二文件 122 段验证，分界也只由第一文件决定：

| 指标 | 统一 | 分速 |
| --- | ---: | ---: |
| 终点中位 / P90，mm | 17.265 / 47.445 | 17.419 / 46.963 |
| 未来轨迹 RMS 中位 / P90，mm | 12.828 / 27.100 | 12.282 / 26.343 |

终点中位略差，差值 +0.154 mm，22 个时间块的重采样范围 -1.901 至 +1.190 mm。收益未重复。该复核是在主结果之后完成，第二文件此前参与过主拟合，故不是新的盲测。

接触分别按入射总速度和法向速度分三段拟合，3 次留出全部落在最高速段，低/中速没有接触测试样本。最低总速度组的摩擦上限雅可比奇异值为零（没有触发上限），该参数不可辨识，不能采用其数值当作低速摩擦结论。

**决定：部署统一 PPQ004，暂不加入分速度切换。** 这是“当前证据不足以支持额外速度适配”，不是证明所有球速都不需要适配。补测应优先覆盖低/中/高速的独立来球与落台，尤其低速接触；控制旋转、速度范围和时间段，检查每个速度区间都有测试样本后再比较连续速度模型。当前飞行测试前缀速度约 1.81–7.21 m/s，不向更高速外推准确性。
