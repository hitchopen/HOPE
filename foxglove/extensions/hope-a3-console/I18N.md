# Console localization

The top-right language selector applies to the HOPE panel. `zh` intentionally
retains familiar technical terms (Runner, Planner, VRPN, CSV, P1/P2); `en` uses
English throughout the authored interface. Robot diagnostics, file names,
addresses, and protocol identifiers remain verbatim.

Language is stored as `language` in Foxglove panel state. The default is `zh`.
Each panel owns its locale: there is no process-wide mutable language. Switching
language merges into saved state, preserves drafts, and sends no robot request.

## Adding a feature

1. Add a descriptive, stable key to `src/messages.en.ts` and its translation to
   `src/messages.zh.ts`. Keep a complete sentence in one entry. Use named
   placeholders such as `{ip}` or `{scale}`, not concatenated sentence fragments.
2. In React components, obtain `t` with `useI18n()` and call `t(key, parameters)`.
   Keys and required placeholder names are checked by TypeScript. Include labels,
   options, tooltips, accessible names, validation messages, and confirmations.
3. Store `message(key, parameters)` descriptors in notice/error state; render
   with `t.text(value)`. Use `LocalizedError` and `errorText` for local errors.
   Nested descriptors stay untranslated until render, including results arriving
   after the operator changes language. Do not save translated strings in state.
4. Pass the active `Translator` to pure presentation helpers. Keep control
   values, service requests, topics, comparisons, and generated commands outside
   translation. Translate their display labels only.
5. Run `npx tsc --noEmit` and `node --test tests/*.test.cjs`. Localization checks
   enforce key/placeholder parity, English-only resources, render coverage,
   language persistence, unchanged controls, and no new inline UI prose.

The small translation module only handles the two supported locales and named
interpolation. If plural rules, dates, or more locales are introduced, replace
the formatter with an established ICU-based implementation behind this API;
do not add per-component language branches or DOM text substitution.
