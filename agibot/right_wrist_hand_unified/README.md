## 插头与套环连接：仅需四颗 M4

保留机器人原机金属套环，拆下假手后将新主体的带平面定位插头插入套环，
从套环外侧四个孔向内拧入 **4 × M4**，连接打印插头内的 **4 个金属螺纹嵌件**。
**不需要第五颗套环安装螺丝；打印插头没有第五个安装孔或嵌件孔。**
若原机套环保留额外的第五孔，该孔留空即可。套环本身不属于打印件。

接口外形取自用户提供的智元零件 **230101218201** 图纸，安装方式参照
[OmniPicker 3 官方手册](https://www.agilink-ai.com/omni-picker3tdf/23.html)。
本模型按用户确认的 A3 假手接口，仅采用四个对角径向孔。
原金属件上连接夹爪壳体的四个轴向小孔也不复制到一体主体中。

| 项目 | 本模型 / 图纸依据 |
| --- | --- |
| 插头外径 | 模型 Ø33.9875；图纸 Ø34 h7，即 33.975–34.000 mm |
| 单侧定位平面到对侧圆弧的总高 | 模型 31.975；图纸 31.950–32.000 mm |
| 定位平面朝向 | yaw 坐标 −Y；平面 Y=−14.98125 mm，外法向 (0,−1,0) |

| 中央孔 | Ø22 mm 开口，连通腕内弯曲线束／接头收纳腔 |
| 圆形承接肩外径 | Ø55.9 mm |
| 套环连接螺丝数量 | 仅 4 × M4；不需要第五颗 |
| 径向孔数量与位置 | 仅 4 孔：45°、135°、225°、315°，绕腕轴均布 |
| 孔内金属螺纹 | 4 × M4×0.7 热熔嵌件 |

嵌件孔按 [SPIROL 151086 短型锥孔嵌件](https://shop.spirol.com/item/metric-thread---tapered-hole---heat---ultrasonic-i/series-14-s-heat-ultrasonic-tapered-insert-metric/151086)
设计：长度 4.70 mm、滚花最大外径 6.32 mm；锥孔入口 Ø5.94、底部 Ø5.74 mm。
入口有 Ø6.4 凹座，嵌件外端安装到距腕轴 16.65 mm 的平面，不可凸出 Ø34 配合包络。
嵌件后保留盲底，不能直接改用更长的嵌件。其他型号需重新核对孔形，不能只按“M4”替换。

先核对原机四颗 M4 的实际头下长度。若头下承压面到嵌件外端的距离为 t，
此设计的目标插入深度为 4.0–4.5 mm，即螺栓头下长度 L=t+4.0 至 t+4.5 mm；
同时确认完整螺纹啮合并避免顶到盲底。官方 M4×8 是其适配法兰的示例长度，不能直接断定适合本 A3 套环。
原金属接口的 1.25–1.5 N·m 扭矩不能视为打印件／热熔嵌件已验证的拧紧值。

**Ø34 h7 的 0.025 mm 公差不能由普通 FDM 直接保证。** 需要打印后测量、修整并试配，
同时保持定位平面、径向孔和外圆同轴；避免用四颗螺丝强行拉入不合适的插头。

## URDF 连接位置与定位

源文件：[A3 乒乓球 URDF](../URDF/A3T2.5-URDF-std-pingpang/urdf/URDF-JOINT-LINK.urdf)。
链路为 `right_elbow_Link → right_wrist_roll_Link → right_wrist_pitch_Link → right_wrist_yaw_Link`，
随后通过固定的 `right_hand_pingpang_joint` 连接手部（源文件第 710 行，xyz/rpy 均为零）。
新手装在腕 yaw 输出端，保留三个腕关节。
普通假手版本 [model.urdf](../URDF/a3_t2d5/urdf/model.urdf) 同样通过固定 `right_hand_joint` 连接到该 yaw link。
左右 yaw 网格的几何一致，最大最近顶点距离约 1.5×10⁻⁸ mm。

源腕网格没有独立套环、定位凹槽或径向孔；它是简化的实体外壳。
本模型将其末端面 **X=48 mm** 作为名义肩面，腕轴为 +X、定位平面朝 **−Y**；
插头自由端 X=38；四条径向孔轴线位于 X=43 截面，并汇交于腕轴 Y=Z=0。
角度从 +Y 朝 +Z 计量，孔向量为 `(0, cosθ, sinθ)`。
腕关节零位时肩面中心在 `right_elbow_Link` 坐标中为 **(283, 0, −10) mm**。

定位平面外法向 **−Y** 与球拍红面法向 **+Y** 平行且反向，因此该键位对应原 URDF 中侧向拍面，
不需要将整只手绕腕轴旋转。用户提供的腕部 13×41 mm 矩形孔位只有 180° 旋转对称性，
四个径向 M4 孔则有 90° 对称性；必须靠这个唯一平面区分径向螺丝的四种安装角度。
13×41 mm 矩形孔中心集合在绕腕轴旋转 180° 后完全重合，因此孔位允许将金属适配器的平面在左右两侧之间切换。
这是孔位几何结论；真实适配器的止口、销位及线束空间没有独立完整模型，不能据此保证所有硬件都可无条件翻转。
本次右侧安装方向已由用户目视确认。

**X=48 肩面仍为名义定位；右侧 −Y 键位已目视确认，但轴向就位深度尚未实测。**
装配时使金属适配器的平面与对应左右手插头一致，保留手部／球拍的设计姿态。
不能用转动整只手来代替适配器方向设置；整只手旋转 90° 会使拍面法向变成 ±Z。
数字模型的插头会与 URDF 中省略内孔的实体外壳重叠，不能将该区域的网格碰撞当成实际配合检查。

主体打印坐标与 `right_wrist_yaw_Link` 毫米坐标的关系：

```text
print_X = yaw_Y
print_Y = yaw_Z + 110
print_Z = yaw_X - 38
```

因此本版定位平面位于 **print_X=−14.98125 mm**；打印轴不能直接当作机器人的 yaw 坐标轴。

压盖使用握柄局部坐标 U（拍面横向）、V（红面法向）、W（柄尾指向拍头）：
`print_X=U, print_Y=88−W, print_Z=V−12.85`。
U=(1,0,−1)/√2，V=(0,1,0)，W=(1,0,1)/√2；
局部原点在 yaw 坐标中为 **(89.252314, 25.728, −88.921686) mm**。
两个打印 STL 已分别摆放，不能直接按各自打印坐标叠放作为装配模型。

## 电线与接头内腔

插头为中空环壁，**不是实心塞**。Ø22 mm 孔从插头入口 X=38 贯穿到腕内，
直段延伸至 X=62；后续腔体沿 (62,0,0)、(70,0,−3)、(78,0,−9)、(84,0,−16) mm 弯向手掌，
采用半径 11 mm 的圆滑过渡，圆顶终点到 X=95。入口至最深处的轴向距离 **57 mm**，空腔约 **22.43 cm³**。

腕壳区域 X≥48.1 mm 验证了完整的 **3 mm 名义包覆壁**，线束腔只向后方腕部入口开放。
安装插头上的四个嵌件仍有独立盲底；螺丝与嵌件不进入线束腔。
**30（轴向）×16×10 mm** 长方体检查块可从入口直接放入，插入路径无碰撞。
这是可用空间检查，不是实测接头规格；实际 A3 接头、护套、线束弯曲半径和余量仍需核对。

官方 [OmniPicker 3 电气接口](https://www.agilink-ai.com/omni-picker3tdf/23.html) 使用 LVC015-M / LVC015-F，
但资料未给出可直接用于本打印件的完整线束包络。装手前先将接头和线束余量收入内腔，
避免夹在肩面、螺丝或定位平面之间。切片不得填实中央孔，腔内支撑必须能从腕部开口取出。

## 装配与球拍位置

1. 清理打印支撑，检查插头外径、定位平面和四个径向孔；安装四个匹配的金属嵌件并复测外形。
2. 对照原假手核对肩面、键位与孔位，插入原机套环，从外侧交替拧紧四颗长度合适的 M4；无需安装第五颗。
3. 从槽背放入五个螺母，卸下压盖，将 H3002 柄直接放入并靠紧柄尾止挡，红面朝开口。
4. 装三颗 M4×20 闭合压盖。压盖与主体耳台有 0.5 mm 名义夹紧间隙，不强行压至零。
5. 核对实际拍面高度、旋转与柄尾位置后，再转印并加工两颗木柄孔；通过压盖窗口放入垫圈和 M4×35，与背面螺母锁紧。

数字装配保持源 URDF 红面中心 **(210.210, 32.078, 32.036) mm**、红面法向 +Y，
坐标系为 `right_wrist_yaw_Link`；柄尾指向拍头方向为 (+X+Z)/√2。
拍柄收腰及柄尾到拍面中心 **171.060 mm** 延用授权的正面图像估算，柄厚为恒定 25.7 mm 包络。
H3002 的真实厚度轮廓尚未测量；模型对齐不能替代实物尺寸与装配基准检查。
H3002 名义拍厚 12.7 mm，与原 URDF 的 13.208 mm 不同；固定红面后黑面相差 0.508 mm。

## H3002 贴合安装后的最终位姿计算

计算前提：柄尾贴紧止挡、三个底部定位垫全部接触、拍柄横向居中；
柄厚采用 25.7 mm、拍厚 12.7 mm、柄尾到拟合拍面中心 171.060 mm。
重新载入最终主体 STL，从三块定位垫和柄尾止挡面独立重建握柄坐标，得到：

| 项目（right_wrist_yaw_Link 坐标） | 最终 STL 重建结果 | URDF / 设计目标 |
| --- | --- | --- |
| 红面参考中心 X / mm | 210.20999895 | 210.21000000 |
| 红面参考中心 Y / mm | 32.07800026 | 32.07800000 |
| 红面参考中心 Z / mm | 32.03600047 | 32.03600000 |
| 红面法向 | (0, 1, 0) | (0, 1, 0) |
| 柄尾指向拍头的 X–Z 夹角 | 45.00000052° | 45° |

参考中心三维误差 **0.00000118 mm**，坐标架角度误差小于 **0.000001°**，均为 STL 数值精度量级。
这些数值验证数字模型，不代表实物测量精度。
该基准与原乒乓球 URDF 以及仓库内 A3PingPong-with-gripper URDF 的右拍基准一致。

名义计算式（毫米）：

```text
B = (89.252314, 25.728000, −88.921686)  # 拍柄尾部中面中心
W = (1/√2, 0, 1/√2)                    # 柄尾到拍头
V = (0, 1, 0)                          # 红面法向
P_red = B + 171.060 W + (12.7/2) V
      = (210.210, 32.078, 32.036)
```

相对 X=48 的名义肩面中心，红面参考点为 **(162.210, 32.078, 32.036) mm**。
腕关节零位时，相对 right_elbow_Link 为 **(445.210, 32.078, 22.036) mm**。

**位姿对齐后，H3002 轮廓与原 URDF 球拍仍有差别：** H3002 黑面位置 Y=19.378 mm，
原 URDF 黑面 Y=18.870 mm，相差 **0.508 mm**；H3002 拍头沿 W 超出参考中心 88.940 mm，
原 URDF 约 76.200 mm，因此拍头向外多约 **12.740 mm**。参考网格横向宽分别约 149.000 与 152.567 mm。
源 URDF 的外形、碰撞网格、质量和惯量本次未替换。

实物误差敏感度：柄尾到拍面中心距离每偏差 1 mm，会使 X、Z 各偏差约 0.707 mm；
例如该图像估算距离偏差 ±3 mm，则 X、Z 各偏差约 ±2.121 mm，这不是已测得的公差界限。
假设拍板在握柄厚度中面对称，柄厚或拍厚每增加 1 mm，贴底安装后的红面 Y 各增加 0.5 mm。
横向偏移 0.5 mm 会使 X、Z 分别偏移约 ±0.354 / ∓0.354 mm；完全贴底并不自动消除槽侧余量。
